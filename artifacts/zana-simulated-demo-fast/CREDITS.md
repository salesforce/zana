# Voice and demo credits

Narration is AI-generated with the stock `af_heart` voice from [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M), using [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx). No person's voice was cloned for this demo.

The model is published under Apache 2.0; the ONNX runtime wrapper is MIT-licensed. This package contains generated narration, not model weights or the speech runtime.

Voice generation ran locally. The share package plays fully offline and does not call a speech service. The app replica, script, timing, and virtual cursor were authored for this Zana walkthrough. Names, tickets, agent output, and plugin installation are fictional.
