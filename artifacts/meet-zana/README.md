# Meet Zana — sharing deck

The Fairy-style introduction is ready in two formats:

- [Shareable PDF](output/Meet-Zana-Introduction.pdf)
- [Editable PowerPoint](output/Meet-Zana-Introduction.pptx)
- [Complete sharing kit](output/Meet-Zana-Sharing-Kit.zip)

The 12 slides introduce Zana, its agent workflows, Projects, Inbox, Library,
architecture, and plugins. New visuals explain project locations, the task
lifecycle, decisions, and saved findings. The kit includes those images and
the complete architecture and plugin artwork as PNG and SVG.
