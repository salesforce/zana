# Getting started

Install Zana, open a folder, and give your agent a task.
Watch the short **How To** videos on the [Getting started page](https://zana-ide.com/docs/getting-started/#how-to-heading)
or find the same videos inside Zana.

## 1. Install Zana

[Download Zana](https://zana-ide.com/download/) for macOS or Windows and open the app.

You need **Node.js 20 or newer** (22+ recommended), **Git**, and at least one
supported agent CLI: Claude Code, Cursor, OpenCode, Codex, or Pi. If the CLI
runs in your terminal, you can use it in Zana.

## 2. Add a project

Click **Add project** in the sidebar and choose your folder. Each project
keeps its threads, terminals, and files together.

## 3. Start a thread

Open **New Chat**, choose your project and agent, and describe what you want
done. Follow the conversation in the thread and check the **Inbox** for
reports and questions.
