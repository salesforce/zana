# Squad guide video 7: labels

- Run a Squad on a schedule: A schedule starts a Squad on a clock, with no one at the keyboard. Open the Scheduler and press New schedule.
- Run as Squad: Set Run as to Squad. Then choose the Squad, the Project, and Squad planning.
- The prompt is the goal and the plan: The prompt text is the Squad's goal. With Plan provided in goal, put the plan there. Schedules skip Launch approval.
- Cadence: interval or cron: Choose the cadence. Use an interval, such as every twenty-four hours, or a cron expression.
- Inbox notifications: Then choose how much each run tells your Inbox: Silent, Quiet or Notify.
- Run now: Press Run now to try it once. The run appears on the Agents board like any other Squad.
- A schedule repeats on a clock: A schedule repeats the same job on a clock.
