# Squad guide video 7: transcript

A schedule starts a Squad on a clock, with no one at the keyboard. Open the Scheduler and press New schedule.

Set Run as to Squad. Then choose the Squad, the Project, and Squad planning.

The prompt text is the Squad's goal. With Plan provided in goal, put the plan there. Schedules skip Launch approval.

Choose the cadence. Use an interval, such as every twenty-four hours, or a cron expression.

Then choose how much each run tells your Inbox: Silent, Quiet or Notify.

Press Run now to try it once. The run appears on the Agents board like any other Squad.

A schedule repeats the same job on a clock.
