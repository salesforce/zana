# Squad guide video 6: labels

- Attach sources: Sources are the files a Squad works from. In the composer, press Attach sources, or drop files in. They appear as chips under Attached sources.
- Project, home folder or clone root: A source can also come from your home folder or the clone root. Each file can be up to four megabytes, and together they can total sixteen.
- Captured when you press Launch: Files are captured when you press Launch, so later edits are not included. Credential stores and app data are refused.
- Worktree isolation: On, Off or Use default: Worktree isolation gives a Squad its own branch and checkout, so it works apart from your folder. You set it on the Squad: On, Off, or Use default.
- When a run finishes: When a run finishes, the Squad decides what happens to the worktree. Keep it, which is the default, merge it into the base branch, or delete it. Only a completed run is merged or deleted. A failed or stopped run is always kept.
- A kept worktree shows in Squad details: A kept worktree shows in Squad details, with its path and branch, so you can review the work before you decide.
- Attach what it needs, choose where it works: Attach what the Squad needs, and choose where it works.
