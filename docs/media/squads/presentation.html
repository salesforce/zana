Anatomy of a Squad

Slots, personas and an orchestrator

  • Slot: one role in the Squad, backed by a persona (prompt, model level, tools).
  • Tab count: how many agents of that persona run.
  • Crown: marks the orchestrator. It launches first and carries the opening prompt.
Define · Step 1

Settings → Squads → New squad

  • Name, icon and a one-line description
  • Add slot for each role and pick a persona
  • Set the tab count for parallel workers
  • Click the crown on the orchestrator
Define · Step 2

Tune how it runs

  • Opening prompt: handed to the orchestrator
  • Default project, or choose at launch
  • Worktree isolation: one shared branch for the run
  • Routing: send work to Low / Medium / High tiers
  • Planning: infer from the goal, or follow your plan
  • Launch approval: let agents start it, or review first
Launch

Describe the goal, pick the Squad

New agent → Squad: type the goal, then choose the Squad and the Project.

You can also start one from:

  • the Launch button in Settings → Squads
  • Schedules and Goals
  • another agent, which can prepare a launch card for you to approve
Run & observe

Watch the work hand off

Board, List and Flow views show every member's status. Squad details shows the plan, work units, blockers and progress.

Human in the loop

It asks. You decide. It finishes.

  • Questions arrive in the Inbox under Needs your answer
  • Answer once and the same run continues
  • If a provided plan is invalid, the run pauses for a correction you approve
  • When an agent launches a Squad, the results report back to that conversation
