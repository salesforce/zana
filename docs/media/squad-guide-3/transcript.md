# Squad guide video 3: transcript

Open the Agents board. Your running Squad is a card, with its status on it. Flow view shows the same run as a graph of who hands work to whom.

Open the card to see Squad details: the goal, and progress for each step. It refreshes on its own while the run is active.

If a worker needs a decision, the run pauses and asks you. The question waits in the Inbox, under Needs your answer.

Choose an answer and continue. A question is not an error. The run was simply waiting for you.

When the work is finished, the Inbox posts Squad completed, with a short summary of the result.

Open Squad details for the full record of every step.

That is the whole loop: find the run, answer when it asks, and read the result.
