# Squad guide 3, Watch a Squad run: label evidence

On-screen labels and spoken names were checked against `website/content/docs/squads-*.md` and confirmed in the built app by the passing recording spec `e2e/demo-squad-guide-3.spec.ts`, which locates each control by its accessible name.

| Caption | Narration |
|---|---|
| Agents board: your run is a card | spoken: Open the Agents board. Your running Squad is a card, with its status on it. Flow view shows the same run as a graph of who hands work to whom. |
| Open the card: Squad details | spoken: Open the card to see Squad details: the goal, and progress for each step. It refreshes on its own while the run is active. |
| Inbox: Needs your answer | spoken: If a worker needs a decision, the run pauses and asks you. The question waits in the Inbox, under Needs your answer. |
| Answer, and the run continues | spoken: Choose an answer and continue. A question is not an error. The run was simply waiting for you. |
| Inbox: Squad completed | spoken: When the work is finished, the Inbox posts Squad completed, with a short summary of the result. |
| Open Squad details: 4/4 complete | spoken: Open Squad details for the full record of every step. |
| Find it, answer it, read the result | spoken: That is the whole loop: find the run, answer when it asks, and read the result. |
