# Squad guide video 5: labels

- Ask an agent to use a Squad: Any agent can start a Squad for you. Ask it to do the work with a Squad, and point it at your plan.
- The agent prepares a launch: The agent checks the plan, then prepares a launch. It does not start anything.
- Squad launch ready, in your Inbox: The prepared launch arrives as a Squad launch ready card in your Inbox. It names the Squad, the planning mode and the files. Nothing starts until you press Launch.
- Review Squad launch, then Launch: Review Squad launch opens the composer, already filled in. Check it, then press Launch.
- Reports go back to the conversation: The Squad runs, and its details show the conversation it started from. When it needs an answer, a Squad report goes back to that conversation.
- Run now: skip the Inbox: To skip the Inbox, ask the agent to run it now. The Squad starts straight away, with no card to approve.
- Review by default, run now when you trust it: Run now suits a plan you trust. Otherwise, the Inbox card keeps you in control.
