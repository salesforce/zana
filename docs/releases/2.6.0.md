# What's new in 2.6.0

**More control over your agents, from setup to finished work.** Start Squad workers when their tasks are ready, choose the skills and models they use, and review messages between threads before delivery. New notification sounds and an optional macOS companion rail help you follow work, while guided Git sign-in makes getting started easier.

## Squads and Personas

- **Start workers when they are needed.** Mark individual workers in a plan-driven CLI Squad to start on demand. Those workers launch when their first task is ready, while the coordinator and other seats can begin immediately.
- **Match the model to the work.** Configure model tiers for supported harnesses and get plan-check advice when a step uses more or less capacity than it needs. Squad routing considers the cheapest eligible worker that fits the task.
- **Choose each Persona's skills.** Set an explicit skill list for Claude CLI and Modern agents, or leave it unrestricted. The Squad's optional lean workers setting reduces worker context; an explicit Persona skill list takes precedence. Other harnesses keep their available skills and show a notice.
- **Set reasoning effort on a Persona.** Save the desired reasoning effort with a Persona and carry it into supported agent launches.
- **Attach content directly to a launch.** Agents can include plans and source text that are not saved as files. Review cards show the captured attachments, and launch results identify renamed or deduplicated files.
- **Run bounded review-and-fix rounds.** Squad plans can reopen a fix task when a review requests changes, with a limit of one to five rounds. Job details show the current review round.
- **Keep Persona guidance with every CLI Squad seat.** Instructions follow workers through launch, restart and restore. Harness combinations that cannot carry the required guidance are refused before launch.
- **Resolve blockers with clearer guidance.** When a coordinator cannot answer a question reserved for the owner, the response names the Inbox card to use. Answering work returns a short receipt, and lost execution bindings explain how to recover.
- **Resume a Goal from its latest run.** The Goals view can reopen the most recent run so you can continue work from the same place.

## Follow work your way

- **Keep a compact Command Center on macOS.** Enable the optional companion in Settings, Experimental to follow agents, handle supported questions and see schedules from a floating screen-edge rail. Open an agent or restore your Zana windows from the rail.
- **Choose notification sounds.** Configure sounds for agent idle and attention events, preview them, adjust volume, and use personal audio or sounds supplied by plugins.
- **Make your own sound provider.** The forkable Sound Studio plugin and agent activity subscriptions let plugin authors build sound experiences around agent activity.
- **Review messages between threads.** A thread's message to a peer waits for your review before the recipient sees it. Pending and delivered states make the handoff visible.

## Easier setup and discovery

- **Sign in to Git with your browser.** Employee marketplace setup checks network access, Git sign-in and marketplace availability in order. When sign-in is needed, use a one-time device code and continue automatically after approval. Existing SSH or credential-manager setups remain supported.
- **Keep setup navigation in reach.** Onboarding has a persistent footer, clearer marketplace and bundle guidance, and the Zana logo throughout setup.
- **Find installed harnesses in Settings.** Plugin-contributed AI harnesses appear alongside the other harness choices.
- **Browse Help videos by topic.** Collapsible categories make the tutorial catalogue easier to scan, including the nine Squad guides. The website adds an interactive walkthrough, an architecture overview and a downloadable presentation.

## Design Docs and file previews

- **Start from richer document templates.** Research, Issue and Product spec templates include supporting files and document-specific agent instructions. Imports recognize document content to choose the appropriate structure.
- **Keep shared documents connected.** Map documents to projects, follow links across projects, and see sync state and reconnect feedback when working across computers.
- **Preview files outside a project.** Configure trusted preview folders for files you need to read beyond the project checkout.
- **Open assistant file links more reliably.** Local links work across desktop platforms, including absolute links into the owning thread's storage.

## Plugin and agent reliability

- **Recover failed plugin pages in place.** Failed panels retain their page and offer reload recovery. Worker bridges also recover more reliably after stalls and API timeouts.
- **Preserve packaged plugin runtimes.** Rebuilds keep published host bundles available, and temporary worker files are cleaned up more safely.
- **Stronger plugin approval controls.** Plugins can block supported native agent tools and request human confirmation across CLI and Modern sessions. Pending confirmations are shown in the session, and failures in blocking checks prevent the tool from proceeding.
- **Keep provider sessions current.** Session environments refresh when agents reconnect, newer Codex error responses are handled, and Modern OpenCode agents receive their intended tools.
- **Load skills more reliably.** Claude skill folders are copied into the bridge environment, and recoverable frontmatter errors produce clearer diagnostics.

## Everyday polish

- **Edit multiline prompts naturally.** Arrow navigation and prompt-history recall work together without unexpectedly replacing a multiline draft.
- **Read replies without overlap.** Pinned prompts leave room for reply text and release when the shortened transcript already contains the answer.
- **Recognize projects at a glance.** Thread tabs use project icons and colors, and Default Project opens in its project view.
- **Return to your terminal.** The project terminal is restored after a visit to Settings.
- **Better desktop details.** Windows caption buttons match the inset title bar, background child processes avoid extra console windows, and quitting development sessions stays responsive after output pipes disconnect.
