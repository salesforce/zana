# What's new in 2.0.6

A Command Center release that turns threads into the main workbench, ships first-party harness plugins, and lets you install and run agents on enrolled machines.

## ✨ New

- **Thread workbench.** Conversations run through a modular thread runtime: plan-execution cards, a shared composer, remappable keyboard shortcuts, and first-party Claude Code, Codex, Pi, and ACP harness plugins.
- **Enrolled machines from the composer.** Install or repair a host daemon from the project picker, Settings → Machines, or an Install chip. SSH remotes wait until the daemon is bound and online before Send.
- **Local agent, remote tools.** An experimental CLI path can keep the agent on this Mac while tools run on the remote host.

## 💬 Improved

- **Remote workspaces are labeled.** Project pickers and the composer show a network badge for SSH remotes and host-bound folders.
- **Provider plugins own their install and skills.** Claude Code, Codex, Pi, and ACP declare native skill roots, health, and install gates instead of in-tree launch code.
- **Plugin SDK.** Secret-request and ask-user-question contracts, plugin services, and monaco/pdf preview plugins.

## 🐛 Fixed

- **OpenCode native roles still pin their own model.** A forced catalog `--model` is dropped when a native role is selected, including from global routing.
- **Composer project pick stays in sync** across Home, Thread, CLI Agent, and Autonomous, and defaults to the sidebar or last-used project.

---

_Nothing to migrate. Existing projects, plugins, and enrolled machines keep working. Pairing another computer still goes through this app's host daemon and the website relay._
