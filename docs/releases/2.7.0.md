# What's new in 2.7.0

Switch to Basic view to focus on a conversation, open a file your agent made beside its reply, or edit Markdown directly in the preview. Settings now puts each AI harness in one place, from sign-in and model choice to CLI launch options.

## Conversations and files

- **Get set up without leaving Basic.** New installs start in Basic view with a setup card. It confirms your default coding agent, checks workplace access for Salesforce accounts, suggests a plugin bundle and shows where to switch to Advanced. Skip any step and come back to it from the sidebar. [#849](https://github.com/salesforce/zana/pull/849)
- **Choose Basic or Advanced.** Switching from a workspace page opens New Chat. If a thread is open, you stay in it with your unsent reply. Basic groups conversations by project and keeps the conversation and its resizable preview together. Switch back to Advanced to use the full set of tools. [#844](https://github.com/salesforce/zana/pull/844) [#846](https://github.com/salesforce/zana/pull/846)
- **Open files from a reply.** A file saved to thread storage can open beside the conversation from a link in the reply. To find it again, open a new side-panel tab and search under **Thread storage**. [#843](https://github.com/salesforce/zana/pull/843)
- **Edit Markdown where you read it.** Search the rendered document, check off a task, or edit across paragraphs in one continuous editor. If another editor changes the file before you save, you can review and reconcile the edits. [#822](https://github.com/salesforce/zana/pull/822) [#839](https://github.com/salesforce/zana/pull/839) [#842](https://github.com/salesforce/zana/pull/842)
- **Ask about a passage.** Select text in a conversation and choose **Ask Zana** to use that selection in a question. You can also select and copy text from a thread’s to-do card or plan panel. [#793](https://github.com/salesforce/zana/pull/793) [#827](https://github.com/salesforce/zana/pull/827)
- **Keep your side panel when work starts.** Launch from a project’s New Chat page and its open panel comes with you. You can also open the shared Agent side panel from Explorer. [#775](https://github.com/salesforce/zana/pull/775) [#808](https://github.com/salesforce/zana/pull/808)

## Experimental Bots

- Turn on **Bots** in **Settings → Experimental**. In Basic view, pin a bot in the sidebar and click it to open its conversation. A first click creates the thread if needed. The sidebar shows five bots at first, with **Show more** for the rest. Bot avatars also identify their threads in the Advanced project tree and Kanban.
- Click the bot’s name above the chat to open its profile in the resizable side panel. Edit its personality in Markdown or manage its routines. Save and Cancel appear when you have unsaved settings.
- Use `zcc bots update` to edit a bot from the terminal. Use `zcc bots routine` to schedule work in its main thread.
- The desktop Vault stores replace-only passwords and Salesforce client secrets with device protection. Connect a Salesforce account to let a bot and its routines read the open cases assigned to that account. Choose a bot service account or authorize your own Salesforce account. The bot receives case details while credentials stay in the Vault.

## Composer and AI harnesses

- **Set up new chats in Settings → Composer.** Choose the default thread harness, its model and supported thinking effort. Threads and CLI agents have independent defaults. In the desktop thread composer, the model comes first, with mode, effort, permissions and Enter behavior together beside Send. New thread launches share the same default permissions. [#791](https://github.com/salesforce/zana/pull/791) [#807](https://github.com/salesforce/zana/pull/807) [#840](https://github.com/salesforce/zana/pull/840)
- **Configure a harness in one place.** Open **Settings → AI Harness**, search for a harness and choose **Configure**. Check credentials, choose a model or search the catalog. The CLI agent switch and launch options are at the bottom of the same entry. [#845](https://github.com/salesforce/zana/pull/845)
- **Choose who sandboxes Claude Code.** A new **Claude Code sandbox** setting is on by default. Turn it off to use Claude Code's own approvals and sandbox settings, while keeping the selected permission mode and workspace write roots. The change applies on the next turn. [#833](https://github.com/salesforce/zana/pull/833)
- **Manage provider access per machine.** Supported providers can start their own sign-in flow from Settings. You can also save API keys in the machine's encrypted store. Install **Provider Usage** from Plugins to see the subscription windows reported by Claude Code, Codex and Cursor across your machines. [#782](https://github.com/salesforce/zana/pull/782) [#785](https://github.com/salesforce/zana/pull/785)
- **See where a setting comes from.** A shared precedence table and indicators explain which settings win across project, harness, persona and Squad configuration. Plugin configuration now lives in Settings, and a search result stays in view as the page finishes loading. [#784](https://github.com/salesforce/zana/pull/784) [#802](https://github.com/salesforce/zana/pull/802) [#814](https://github.com/salesforce/zana/pull/814)
- **Switch threads without a misleading model warning.** Opening an existing thread from Explorer or moving between conversations no longer briefly reports the saved model as unavailable. [#818](https://github.com/salesforce/zana/pull/818) [#824](https://github.com/salesforce/zana/pull/824)

## Squad plans and runs

- **Fix a plan before launch.** Review plan flags steps that require a role the Squad cannot supply. It suggests corrections and lets you send a fix request back to the conversation that prepared the plan. It also accepts common variations in spacing and capitalization.
- **Keep work with the right role.** New runs enforce every required role on a step. If no worker can take it during a run, the coordinator or a person can resolve the blocker. Approved plans are checked again at launch. Runs already in progress keep their original routing. [#794](https://github.com/salesforce/zana/pull/794)
- **See why a worker stopped.** Squad runs report worker launch failures, recover interrupted work more reliably and honor Stop while workers are starting. [#837](https://github.com/salesforce/zana/pull/837)

## Platform, privacy and reliability

- On Windows, Zana finds npm-installed Claude Code and uses npm to update it. Squad launch snapshots use Windows-safe folder names. When no shell is configured, Zana picks an installed shell. Terminal settings now explain which option controls OSC 52 clipboard copies. [#725](https://github.com/salesforce/zana/pull/725) [#815](https://github.com/salesforce/zana/pull/815) [#768](https://github.com/salesforce/zana/pull/768) [#766](https://github.com/salesforce/zana/pull/766)
- Harnesses declare whether they report API errors for resume. An agent’s **Needs you** indicator clears when its approved tool finishes. Codex recovers stale turns, Claude preserves pending input until it is consumed, and ACP handles command failures and replacements more reliably. Browser results survive an activity-log write failure, and unrelated changes in a Git plugin repository no longer trigger scoped plugin updates. [#783](https://github.com/salesforce/zana/pull/783) [#813](https://github.com/salesforce/zana/pull/813) [#782](https://github.com/salesforce/zana/pull/782)
- The update removes the first-party PostHog integration and its saved settings. Plugin settings redact secret defaults, dependency parsers handle malformed input more safely, and plugin starters safely encode display names. The website also updates Next.js. [#763](https://github.com/salesforce/zana/pull/763) [#771](https://github.com/salesforce/zana/pull/771) [#823](https://github.com/salesforce/zana/pull/823) [#792](https://github.com/salesforce/zana/pull/792)
- The first-project tutorial now includes narration. The Plugin Guide covers more surfaces and scales its wireframes as a single picture. [#799](https://github.com/salesforce/zana/pull/799) [#841](https://github.com/salesforce/zana/pull/841)
