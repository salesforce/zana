# What's new in 2.0.1

A maintenance release focused on local-machine recovery, plugin uninstall, and plugin panels that still work when a package has no dedicated nav slot.

## ✨ New

- **Relaunch the local harness** from Settings → Machines. The primary machine can restart its host daemon without leaving the app.
- **Uninstall plugins from the Plugins hub.** Removing a plugin now clears both a PluginService install and leftover disk entries. Built-in compiled modules stay out of Installed unless they are actually installed.

## 💬 Improved

- **Plugin panels in a split workspace** fall back to the compiled module panel when a plugin does not register a nav panel, so those views still fill the slot instead of going blank.
- **Installed plugin rows** use a real chevron button, so expand/collapse is keyboard-accessible.

## 🐛 Fixed

- **Plugin uninstall** no longer leaves an orphaned disk entry that could reappear after a restart.

---

_Nothing to migrate. Existing projects, plugins, and enrolled machines keep working._
