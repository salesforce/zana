# What's new in 1.0.2

Staying up to date got easier, and the inbox got more useful.

## ✨ New

- **A new About screen.** See your version and update status at a glance, with a clear card that tells you when an update is ready.
- **Automatic updates, no sign-in.** The app now checks for new versions on its own — no token, no VPN, no account required.
- **Save messages for later.** A new Saved tab in the inbox keeps the reports you want to come back to.
- **Start an agent from anywhere.** Spin up a new agent straight from an inbox message or a document in your Library.

## 💬 Improved

- **Images preview inline.** The file explorer shows pictures instead of a placeholder.
- **Agent catch-up.** An agent's summary is now a tidy popover you open when you want it.
- **Follow-ups** show when each item was last set aside.
- **Select and copy text** in the Inbox, Follow-ups, and Library.

## 🐛 Fixed

- The app reliably claims its spot in the Dock at launch.
- Diffs render correctly everywhere they appear.
