# What's new in 1.0.6

A big harness-and-chat release: talk to agents through a richer chat surface, run more model backends, watch your spend, and publish extensions to a real marketplace — plus a redesigned website and a leaner Settings.

## ✨ New

- **A richer chat surface.** See exactly what an agent did with a master-detail tool inspector — every tool call, its raw name, its inputs and outputs, and how long each one took. Steer a running agent or queue a follow-up as two distinct message lanes, drop diagrams into the conversation (with selectable text and one-click Mermaid export), and `@`-mention files right in the composer.
- **More model backends.** A new native harness brings Codex to full lifecycle parity with Claude and adds a provider-agnostic launch experience, so you can start work against the backend you want with one consistent flow.
- **See what you're spending.** A new Usage dashboard in the sidebar surfaces per-session and rolled-up cost and token usage, with a live token badge so you always know where a run stands.
- **Publish extensions to a marketplace.** Publish your extensions through an authenticated CLI and a new publisher dashboard, and browse a served registry of signed, verifiable releases — end-to-end from publish to install.
- **A microVM execution environment.** Run agent-executed code inside an isolated microVM (microsandbox) with a scrubbed environment and clean teardown. It lives under Settings → Experimental while it matures.
- **Quick Prompts, leveled up.** Author reusable prompts in-app, template them with arguments, and use agent-interview mode to have an agent draft the prompt with you.
- **One-click authorizations.** Auto-configure your agent authorizations from Settings, and opt into "Trust all ZCC tools" to skip per-call approval prompts when you're ready.
- **Follow the OS.** A new "System" appearance mode tracks your operating system's light/dark setting automatically.

## 💬 Improved

- **A calmer inbox.** Blocking questions stay quiet until an agent goes idle, every feed row leads with an always-on timestamp, and you can toggle the feed between Project and Time groupings. Rows carry richer context/intent, pinned questions get their own band, and read rows gray out.
- **Cleaner Settings.** The experimental Teams surface is gone (Squad replaces it), the microVM isolation toggle moved to the Experimental tab, and harness tokens now show a "Set" badge when stored.
- **Open where you work.** Open-in-editor buttons in the agent detail panel, with a graceful fallback to `open -a` when an editor's CLI shim is missing.
- **Squads.** Run squads in yolo mode, collapse a squad into a single card, and get richer node rendering in the Squad Flow view. A squad's whole team now shuts down cleanly when its lead exits.
- **A faster, prettier GUS board.** Board loading is quicker and more polished.
- **A redesigned website & docs.** A modern, dual-theme site with a ⌘K search palette, syntax-highlighted docs, and a fresh art direction — plus an accessibility, contrast, and SEO sweep.

## 🐛 Fixed

- **A smoother terminal.** The mouse wheel now scrolls the terminal itself instead of the program running inside it, and accented and non-Latin characters display correctly instead of turning into underscores.
- **Terminals launch reliably after long uptime.** A slow leak of the system's terminal slots could eventually stop new terminals and agents from starting; sessions now free their slot the moment they end, so the app can run for days without running dry.
- **Quieter Codex logs.** Codex no longer fills its log with spurious "invalid stop hook JSON output" messages.
- **Menu bar.** Removed the cramped inline reply drawer from the menu-bar popover.
- **Agents.** "Mark as Idle" is now available for triage-promoted agents (button and right-click menu), your New Agent instructions stick around if you close and reopen the launcher, agent diffs include newly created files, and duplicate board headings are gone.

## 🔒 Security

- **Dependency update.** Updated a dependency (zod) to a version that resolves a known security advisory.

---

_Some capabilities (microVM isolation) are opt-in or experimental — enable them in Settings when you're ready. The multi-model Chat engine is always available; pick a model from the composer or set a default backend in Settings → Experimental._
