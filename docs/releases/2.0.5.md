# What's new in 2.0.5

A reliability release for updates, browser-style navigation, and OpenCode role launches, with Zana's new public home.

## 💬 Improved

- **Zana has a new public home.** Website and documentation links now point to [zana-ide.com](https://zana-ide.com/).
- **One official release feed.** Signed Apple Silicon and Intel builds now publish only to the public `salesforce/zana` release feed.

## 🐛 Fixed

- **“Restart now” reliably installs downloaded updates.** The update action now completes its IPC response before quitting and treats the button as confirmation to end live sessions, so the quit warning cannot silently cancel installation.
- **Nested pages survive reloads.** Directly opening or refreshing routes such as Settings resolves renderer assets from the app root instead of returning missing files.
- **OpenCode roles keep their configured model.** Launching a native role no longer injects a conflicting global or per-tab model, and the model catalogue reflects the current gateway identifiers.

---

_Nothing to migrate. Existing projects, plugins, and enrolled machines keep working._
