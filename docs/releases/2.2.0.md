# What's new in 2.2.0

Zana 2.2.0 brings your Inbox, diffs, and connected tools alongside agent conversations. It adds Agentforce Code, expands the Salesforce workbench, and makes it easier to find and return to active work.

## ✨ New

- **Agentforce Code.** Use an ACP-enabled `afcode` installation in Modern threads or launch its native CLI Agent. Choose the executable in Settings and use its existing authentication. This first release supports local CLI launches; ACP history, plans, and host-tool access depend on afcode's current capabilities.
- **Inbox beside your conversation.** Open a project's Inbox in the session side panel to read reports, inspect attached documents, and answer questions while keeping the conversation in view. Shared report rendering includes copy and PDF export.
- **Salesforce workbench.** The Salesforce project tab brings together Overview, Data, Apex & logs, Deployments, and Agentforce. Choose a target org per project, retain query and form drafts, and revisit recent operation results.
- **Salesforce side panels.** Open org details, SOQL, objects, records, Apex/logs, deployments, and operation history beside Modern threads and CLI Agents. Panels can pin their own org, and selected evidence can be added to the prompt. Plugin authors can reuse these panels and UI components.
- **Full-page sessions and in-app shells.** Open CLI Agents and threads as full pages, and let agents open visible shell terminals inside Zana.

## 💬 Improved

- **A clearer Inbox.** Report details use a focused reading layout, compact session status, and a docked reply area with Open, Resume, or Reopen actions.
- **Faster navigation.** The command palette searches commands, projects, and threads, while Favorites and Notifications use a consistent quick-access layout.
- **A more useful new-tab page.** Session side panels group essentials, plugin tools, and files into searchable categories. Plugins can name their own panel categories.
- **Diffs in tree or list form.** Switch between a file tree and a flat list with inline diff previews when reviewing agent changes.
- **Better model search.** Model pickers rank substring and segment matches so partial names are easier to find.
- **More control on the Agents board.** See the running-schedule count, hide scheduled sessions consistently, and close eligible CLI Agents from a lane's context menu.
- **Marketplace browsing.** Filter plugins by marketplace source and load catalogs from supported GitHub repository URLs.

## 🐛 Fixed

- **Thread permissions persist.** Follow-up messages, queued sends, resumed sessions, and forks retain the thread's selected permission mode within the host's allowed policy.
- **Queued messages respect startup.** A second message stays queued while the first dispatch is starting, and queue changes update the thread view immediately.
- **Project navigation stays in context.** Leaving a focused project returns to the appropriate global view; opening an inspector no longer unexpectedly changes project scope.
- **Split dragging does not also open a session.** The click that starts a split-pane drag is consumed.
- **Team launches are checked before dispatch.** Admission checks catch unsupported launch requirements before workers start.
- **Agent write scopes resolve correctly.** Relative paths are resolved against the session's working directory, and paths escaping that directory are rejected.

---

_macOS downloads are provided for Apple Silicon (`*-arm64.dmg`) and Intel (`*-x64.dmg`). Agentforce Code requires an ACP-enabled installation for Modern threads. Salesforce tools require the Salesforce CLI and an authenticated org._
