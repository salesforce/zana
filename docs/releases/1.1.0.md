# What's new in 1.1.0

A more capable Command Center release: a new Home dashboard brings the work that needs attention into one place, report delivery is more dependable, extensions can contribute richer agent capabilities, and the app is sturdier after long-running sessions.

## ✨ New

- **A Home dashboard for the whole workspace.** See open follow-ups, unread Inbox activity, and active agents across every project in one place. It includes quick links into the full views plus short, actionable guides for creating extensions, scheduling work, personas, shortcuts, and the first-run tour.
- **A focused notifications drawer.** The title-bar bell now opens a lightweight view of unread questions and reports, so you can triage what matters without leaving your current work. Native notification clicks open the matching Inbox item directly.
- **Extensions can bring agent capabilities with them.** Extension manifests can now declare bundled skills and MCP servers, and extensions can run install/uninstall lifecycle hooks. The app keeps those contributions in sync with consent and removes extension-owned state when an extension is uninstalled.
- **Report files no longer fall through the cracks.** When an agent creates a report-like markdown file but forgets to post it, Command Center can automatically link it to the Inbox and the agent's Report panel as soon as the agent goes idle. This is on by default and can be changed in Settings.

## 💬 Improved

- **A clearer agent workspace.** The agent inspector now has a Report stage for reading the reports associated with that agent, and Inbox deep links retain their selected item even when the feed is collapsed or capped for display.
- **Better extension and ticket integrations.** Extensions can push Inbox entries through their granted capability, contribute more complete agent setup, and the Tickets extension exposes its newest project and version data through the brokered MCP connection.
- **A more polished desktop experience.** Agent details can be viewed full-screen, the Inbox launcher keeps Send in reach, the chat labels tool-running turns as "Working," and the default chat model is selected automatically when you start a run.
- **More useful Settings and setup.** Settings labels and selectable values are clearer, the shared voice key is used consistently, and harness repair messaging better explains what the action does.

## 🐛 Fixed

- **Long-running terminals recover after sleep.** The app now independently reaps dead terminal sessions on a regular interval and immediately after wake, preventing lost process-exit events from eventually exhausting macOS terminal slots.
- **Fewer background and UI glitches.** Extension navigation badges stay current, runtime extension backgrounds load reliably, the app avoids spurious IPC listener warnings, and agent profile icons no longer carry an unnecessary project-colored ring.

## 🧪 Experimental

- **Content Screen.** An optional experimental safeguard can inspect externally sourced tool results for likely embedded prompt-injection instructions. It warns the agent rather than blocking work, supports a dry-run mode, and is off by default while it matures.

---

_The optional Content Screen is available in Settings → Experimental. Auto-link report files is enabled by default in Settings → Agents; it uses filenames only and does not spend model tokens._
