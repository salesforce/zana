# What's new in 2.2.2

Zana 2.2.2 brings a live browser preview and a fuller Agentforce Studio. Threads keep their models and previews steadier as you move between projects, and the website now uses the Fairy identity.

## New

- **Browser preview.** The Browser Automation plugin can show a live headless browser preview beside the thread.
- **Agentforce Studio.** Studio adds action authoring, an org login flow, draft recovery, and Save as, so an unsaved script survives tab switches and can be written as a new file when the original changed on disk.

## Improved

- **Composer models stay put.** The model list remains available when you switch projects or hosts.
- **Thread previews and activity.** File previews and activity labels stay aligned with the conversation as the thread updates.
- **Project settings.** Settings navigation opens the matching project section instead of dropping you on a generic page.
- **Docs plugin.** The Docs plugin stays available through its install and enable lifecycle.
- **Website.** The public site is redesigned around the Fairy identity, with matching architecture and plugin artwork.

## Fixed

- **Sticky inbox actions.** Inbox row actions no longer stick to the wrong item after the feed updates.
- **Changes panel colors.** The Changes workbench follows the active theme, including light mode.
