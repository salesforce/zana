# What's new in 2.0.3

A Command Center release focused on closing work with a paper trail, following Threads as well as CLI agents, and one pannable board for Agents and PRs.

## ✨ New

- **Close with follow-up on Threads.** The same “summarize, file leftover work, then close” action CLI agents already had is now on thread cards, the thread overflow menu, and the inspector.
- **Follow Threads.** Starring a thread puts it in the followed drawer next to starred CLI agents, grouped by blocked / working / idle.
- **Image previews in Threads.** PNG, JPEG, GIF, and WebP files render in the file-preview tab and timeline instead of failing as text.
- **A shared pannable kanban.** The Agents board and the PR Monitor board use the same canvas: drag empty space or two-finger scroll to pan.

## 💬 Improved

- **Pending-approval banners** spell out the command, paths, and permissions in play, and approval choices are keyboard-navigable.
- **Open in split** can keep Home, Agents, or a plugin pane beside the thread instead of only replacing the current view.
- **Scheduled agents appear on the Agents board by default.** Waiting jobs sit in a Scheduled lane. Turn this off in Settings → Agents if you want those runs only on Scheduler and in the inbox.
- **Plugin Guide chips** sit on the visible badge after scale, so annotations stay aligned on the map.

## 🐛 Fixed

- **Binary project files** are read as base64 with a dedicated size cap, so image previews do not trip the text-file limit.

---

_Scheduled jobs now show on the Agents board unless you already set that toggle. Existing projects, plugins, and enrolled machines keep working._
