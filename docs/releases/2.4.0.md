# What's new in 2.4.0

**More ways to follow your agents and build your own plugins.** Zana 2.4.0 adds Agent City, shared contextual help, and a smoother path from local plugin development to a marketplace submission. This release also adds Windows x64 installer builds and improves desktop, phone, and remote conversations.

## New

- **Agent City.** Install the Agent City plugin for another way to see your running agents. Plugins can now contribute views to the Agents screen alongside the existing views.
- **Help where you need it.** Turn on contextual help from desktop or mobile to see guidance for the controls you are using. The same preference applies across both layouts.
- **Prepare a plugin submission.** Installed local plugins can prepare a marketplace submission draft, with validation guidance and updated authoring documentation.
- **Windows x64 builds.** The desktop release pipeline now builds a Windows installer alongside the Apple Silicon and Intel Mac packages.

## Improved

- **Local plugin development.** Zana keeps the build tools needed by authored plugins, refreshes development panels after changes, and reports build failures more clearly.
- **Long conversations and busy projects.** Conversation history, terminal output, Inbox reads, and Tasks lists do less unnecessary work as they grow. Hidden terminals avoid resizing during navigation, and editors load when needed.
- **Phone conversations.** More stable chat scrolling and swipe-to-close navigation make it easier to move between agents. Task headings retain their intended size on mobile.
- **Remote installation and recovery.** Machine setup uses a clearer installation panel, and packaged builds include the installer needed to repair a remote connection.
- **Slack conversations.** Remote conversation presentation follows its controlling surface, and thread replies can use plain text for more readable conversations.

## Fixed

- Provider frames, recordings, subprocess output, and uploads stay bounded, and child-process resources are released when their work ends.
- Thread refresh continues while work is running and picks up the final output.
- Background browser automation keeps its pages hidden instead of bringing an unrelated conversation's preview to the foreground.
