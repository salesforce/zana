# What's new in 2.0.4

A Command Center release that ships Intel and Apple Silicon from the same tag, calls a project a project, and gives schedules a real page.

## ✨ New

- **Intel Macs get the same signed build.** This is the first dual-arch GitHub release (Apple Silicon + Intel). Auto-update serves the right zip per machine.
- **A schedule page.** Opening a job from Scheduler or the Agents board goes to a dedicated schedule view with the same split chrome as threads.
- **Product tour on the website.** The public site has a looping tour, a Features page, and a README GIF of the workspace.

## 💬 Improved

- **Projects, not workspaces.** Sidebar, overview, command palette, and “open in …” copy say Project. Saved sidebar order still maps the old Workspaces section.
- **Agent inspector actions** (mark idle, delete, close with follow-up) are shared between the modal and the session page.
- **Scheduled lane sits on the right** of the Agents board. The board’s scheduled-jobs toggle remembers your choice.

## 🐛 Fixed

- **Scheduled runs** cannot stack forever: a max-duration watchdog and a concurrent-fire guard stop overlapping fires.
- **Subagents** are not closed when a parent scheduled run finishes.
- **Scheduled process trees** are cleaned up when a job ends.

---

_Nothing to migrate. Existing projects, plugins, and enrolled machines keep working. Intel users who could not take 2.0.3 can update now._
