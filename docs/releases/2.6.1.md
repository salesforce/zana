# What's new in 2.6.1

**Setup in tabs, steadier Squads and working tools on remote machines.** Connecting machines and adding projects now happens in ordinary application tabs alongside your threads. Squad runs that wait on a human answer no longer time out early, and Claude threads on remote machines can use their tools again.

## Setup and navigation

- **One tab bar for threads and setup pages.** Threads and setup pages share the same application tabs, with shared search, ordering, keyboard navigation and close commands. A setup page keeps its draft when you switch tabs.
- **Add projects from the machine they belong to.** The Machines header + opens Connect a machine. Each machine's + opens a menu for Add folder, New folder, Clone from Git and supported plugin project creators, and the setup page keeps that machine as its target.
- **Re-pair a machine over SSH.** When you re-pair a machine, you can choose SSH instead of the installer command. Re-pairing over SSH repairs the existing machine rather than adding a duplicate.
- **See when plugin catalogs are out of date.** Browse shows a status pill for your catalog sources, with one-click Refresh for sources that are out of date or failed, and per-source detail. Stale sources refresh when you open Browse and during update checks.
- **Reuse your GitHub CLI sign-in during setup.** When marketplace Git access fails, setup retries once with an existing `gh` sign-in for that host, without changing your Git configuration. Errors now distinguish authentication, network and certificate problems.

## Squads and Personas

- **Wait for human answers without timing out.** A Squad run that is waiting only on an open blocker pauses its idle deadline, up to a configurable bound (4 hours by default). You get one warning before it stops, resolving a blocker counts as progress, and parked workers are no longer reaped while the run waits.
- **Consistent launch settings everywhere.** Launches from the composer, the CLI, agents, Goals and the Scheduler resolve worktree isolation, checkout target, completion, push permission, named checks and retry limits the same way. An active run keeps the settings it started with.
- **Run named checks with bounded retries.** Squad owners can define named checks and limit failure retries.
- **Avoid losing editor changes.** The Squad and Persona editors ask before discarding unsaved edits on Cancel, Close, Escape, Delete or Reset.
- **See member roles in the Squad list.** Each member shows its Squad label, with its Persona as a chip.

## Agents and plugins

- **Tools work again on remote machines.** Claude threads on remote machines no longer deny every tool call. Native tool policy checks now reach the server through SSH pairing and Zana Connect.
- **Side-panel agents know the open page.** Agents beside a plugin page receive the current page, resource and file with each message, including after navigation, and can read live content when needed.
- **Side panels on global plugin pages use your selected project.** A conversation started beside a global plugin page, such as one with its own project picker, now runs in the project you selected.

## Everyday polish

- **Message actions no longer cover the next prompt.** The action bar under an assistant reply sits on its own line.
- **Videos open with the Zana intro.** Every Help video now starts with the Zana logo.
- **Cleaner sidebar.** The unused Command Center shortcut button has been removed from the sidebar footer.
