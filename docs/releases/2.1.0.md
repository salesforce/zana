# What's new in 2.1.0

A Command Center release that adds Grok Build, live CLI plans, and shared composer defaults, with finer control over what agents are told.

## ✨ New

- **Grok Build.** A first-party Grok harness plugin shows up in the fleet and composer when the CLI is installed. Hide it from Settings like the other harnesses.
- **Live CLI plan panel.** Plan-mode Claude, Cursor, and OpenCode sessions pin a Plan view with waiting copy and safe file-preview links.
- **Agent guidance.** Settings → Agents can opt out of product introduction/RULES.md, remote-access instructions, and bundled skills.
- **Shared last project.** Unpinned Modern, CLI Agent, and Autonomous composers remember the last project immediately, so the sidebar and pickers stay in sync.

## 💬 Improved

- **CLI Agent uses the same model catalog as Modern**, including remote hosts and fallback rows.
- **Pending interaction banners collapse** behind an attention dot so they do not dominate the thread.
- **Remote composer attachments** stage to the host before launch, including dropped paths and clipboard images.
- **Native OpenCode roles stay gated.** Project-specific agents stay off until Settings enables native-agent discovery.

## 🐛 Fixed

- **Accept Edits is the CLI's native permission policy.** It no longer emits extra auto-approve flags or an interactive execution-consent dialog.
- **Streaming markdown tails repair** incomplete inline markup without touching fenced code or plugin directives.
- **Versioned Claude model ids** with a `[1m]` suffix resolve in live target selection.

---

_Nothing to migrate. Existing projects, plugins, and enrolled machines keep working. Pairing another computer still goes through this app's host daemon and the website relay._
