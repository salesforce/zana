# What's new in 2.3.6

## New

- **Built-in Squads.** Research, Design, Debug and Delivery squads provide tiered worker pools for common development work. Debug and Delivery can route work to matching worker tiers, while Review remains an on-demand squad.

## Improved

- **Squad routing controls.** Set routing enforcement per squad with Use default, On or Off. The control persists in squad overrides and falls back safely when a worker model tier is unavailable.
- **Orchestrator routing.** Built-in Orchestrator uses the medium model tier without pinning a harness. Project and global routing select its runtime; per-tab and persona overrides remain available.
- **Neutral built-ins.** Code Reviewer and Orchestrator use only their assigned model tier and generic role prompt. Project or global harness routing selects their runtime.
