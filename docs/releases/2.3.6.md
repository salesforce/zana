# What's new in 2.3.6

**A sharper Agentforce Studio, fetching an agent and its dependencies from your org, steers that always land, and machines that pair even when Zana Connect says no.** Zana 2.3.6 focuses the Studio on the agent you have open, opens Ask agent as a composer you control, retires the legacy relays in favor of Zana Connect, and fixes a set of thread, host and composer issues.

## New

- **Fetch latest from org.** A button in the Salesforce tab checks what changed in the org, retrieves the components you pick into a temporary folder and shows each file before anything is written. Files you edited locally are listed as conflicts with a diff, and you choose Keep local or Take org for each one. The check follows the open view (Agents, Apex & LWC or everything), and agents can run the same fetch through the workbench.
- **Fetch an agent with its dependencies.** The agent bar has a Fetch button that checks the open agent, its newest org version, and the Apex classes, Flows and prompt templates its actions call. References missing from the org are listed. The fetch dialog opens on a summary with one action per group, and its full list has a name filter. Fetch latest now also covers Flows and prompt templates.
- **Open in Agentforce Builder.** A toolbar button opens the current agent in Agentforce Builder in Chrome, behind the org read check, without exposing the session URL.
- **Simulate and Live preview.** Preview offers Simulate and Live. Clicking Start or Send in Preview is the approval, so the run starts without a confirmation in a thread. Runs started by an agent still ask.
- **Ask agent opens a composer.** Ask agent in Design Docs and plugin project tabs opens the side-panel composer prefilled with the request. You pick the harness and send; nothing starts before that. Panel conversations about a doc join that doc's Agents list.
- **Design Docs and Salesforce come installed.** New and existing installs get the Design Docs and Salesforce plugins enabled by default. If you uninstalled either one, it stays uninstalled.
- **Tiered Squad workers.** Built-in Squad Worker personas come in low, medium and high tiers, and the built-in personas now use tiers instead of fixed models. Each Squad can turn tier routing on or off, or follow the global default. The Architect persona remains for existing Squads; new Squads should use Squad Worker (High).
- **City themes in Agent City.** Agents → World has a City theme picker: Green city, San Francisco and Zürich. Themes change the artwork only; plots, counts and agents stay the same, and the choice is saved per view.
- **Customize the sidebar.** Customize navigation lets you show, hide and reorder sidebar destinations, with Restore defaults to undo. More is now an icon button beside Settings, and a dot marks it when the current page is hidden.

## Improved

- **Studio focuses on the open agent.** The explorer shows the open agent's actions and references, with an All agents button to go back. It can be resized and shows the dependency outline with an exact count of org agents.
- **Flow and Apex tabs get their own header.** Save, Preview and Publish show only on the agent tab. Flow and Apex tabs show their name, type and status, a Project / Org switch with a drift dot, and what a Flow reads, writes and calls, with Map, Source, Contract and Used by tabs. The Project / Org choice is remembered per project.
- **Org copies match the project format.** The org side of an Apex class or Flow is retrieved in source format, like the VS Code extension, so comparisons line up and an inactive Flow shows its latest version. Fetched files go to the package folder that already holds the component.
- **Close editor tabs from a menu.** Right-click a tab (or press Shift+F10) for Close, Close others, Close to the right and Close all.
- **Compact Design Docs list.** Rows fit on one line with the summary in the tooltip, Draft no longer shows a pill, rows quote the newest open comment and its author, projects get a color, and docs an agent changed since you last opened them are marked.
- **Safer agent worktrees.** New managed worktrees start from a freshly fetched default branch instead of whatever branch was checked out. Automatic cleanup waits 5 minutes after an archive or exit and keeps a worktree that has uncommitted or untracked changes.
- **Agent browser logins persist.** Each thread's agent browser tabs share one profile, so logins survive new tabs and app restarts without crossing threads.
- **Studio toolbar.** Save is a split button with Save as… in its menu, Publish is the primary action, and Compile is an icon button. Editor tabs scroll horizontally.
- **Agents list.** Rows are compact, project agents come first, each row has its own Retrieve, and org agents that have a local copy appear under In this project.
- **Large agents.** Agent Script sources up to 10 MB can be previewed, saved and retrieved.
- **Action details show only what applies.** An Apex action without declared parameters hides Inputs & outputs, a reference opened from outside the script hides Used by, and the unused Last preview tab is gone.
- **Apex, Flow and Lightning Type sources in large projects.** Sources in the standard project folders open even in large repositories. When a source is missing, the message points you to the Org switch.
- **The Studio Assistant uses the side-panel agent.** It opens the shared side-panel conversation linked to the current file, and falls back to the in-rail chat when no panel agent is available.
- **New threads use your default harness.** Plugins that start a thread without naming a provider use the default harness from Settings.
- **Inbox updates live.** Items pushed by threads, plugins and schedules appear in the desktop Inbox right away, and a Refresh button reloads it.
- **Release view.** Publishing shows compact status rows with retry per step and a clear Publish action.
- **Pending agents in background activity.** Agents that are still starting show in the background activity list.
- **Clearer refusals.** Salesforce actions that are blocked explain why, instead of showing an internal headless message.
- **Pi on Windows.** Pi starts through Node directly, so its bridge channels work, and managed installs can update themselves.
- **Dictation follows the Experimental switch.** The mic now appears in every composer only when Voice input is enabled in Settings → Experimental, so it no longer shows up by default in agent and Squad composers. The mic is disabled, with the reason on hover, when no computer is connected, more than one is connected, or the connected computer has no Codex login or `OPENAI_API_KEY`. It re-checks when a computer connects or disconnects, and when you return to the window after running `codex login`.

## Fixed

- **Tool policy fails closed.** Native tool calls are denied until every enabled policy plugin is ready, including while one reloads, instead of being allowed during that window.
- **Thread open shows the right browser.** Opening a thread replaces a stale inspector, so it no longer covers the thread or keeps its browser hidden.
- **Reduced motion in Agent City.** The motion control shows the reduced state as soon as the system asks for reduced motion.
- **Steers are never dropped.** A steer sent while a session starts, as a turn ends, before the first turn's session exists or while the machine reconnects is held and delivered to the live turn, or starts a new turn when the thread is idle.
- **Machine pairing falls back to SSH.** When Zana Connect refuses, revokes or can't be reached for enrollment, installing or repairing an SSH machine uses the SSH tunnel instead of failing with "Enrollment denied or access revoked". Remote install and pairing work end to end.
- **Composer environment error.** Opening a thread no longer shows "environment does not belong to this project and machine" in the composer while it loads.
- **Broken skill files stay out of the composer.** A skill with invalid frontmatter no longer puts a red error on every new chat. The Skills view lists it with the file line and the reason.
- **Agent preview.** Agent preview works again in the Studio, and the agent editor has a Preview button. Live preview no longer times out after 20 seconds, and you can select text in Preview.
- **Agentforce Builder and publishing.** Open in Agentforce Builder opens the right agent version, and publishing works when version details can't be read.
- **Host offline banner.** The composer shows one host-offline message instead of several, and reloads when the host reconnects.
- **Remote installs replace old daemons.** Installing on a remote machine stops any daemon already running for that host, and the reconnect popup no longer reports the tunnel as timed out while the install is still running.
- **HTML previews.** HTML file previews are served with their own content security policy.
- **Browser side panel.** Scoped CDP automation works in the side-panel browser, login popups open as native windows, and closed tabs are cleaned up. Previews no longer show the phone-sharing row.

## Removed

- **Legacy phone and machine pairing relays.** Zana Connect is now the only way a phone reaches your computer, and machines pair over Zana Connect or the SSH tunnel. A phone relay connection saved in an older version shows as not connected; sign in with Zana Connect in Settings to reconnect. The Settings relay field is now "Public app URL".
