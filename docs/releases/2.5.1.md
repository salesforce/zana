# What's new in 2.5.1

**More dependable Squads, richer context and clearer scheduling.** Resume Squad agents with their work intact, choose what happens to a completed run’s worktree, and share selected passages with assistants. This update also improves scheduled runs, plugin installation and everyday desktop behavior.

## Context and conversations

- **Annotate a passage in a thread.** Select text from a conversation and attach an annotation as context for your next message. Browser plugins can also contribute annotation actions to the browser toolbar.
- **Share selections without filling the composer.** Copy text from participating editors, documents and plugins, then paste an inspectable context badge into a thread or assistant composer. The captured text travels with your message, and compact references survive draft restoration and conversation history.
- **Ask an agent from Design Docs more reliably.** The assistant resolves the correct project machine, offers more room for agent selection, and accepts inspectable document passages as context.
- **Give previews more room.** Widen the document preview panel to read larger files, with safer handling of project file paths across platforms.

## Squads

- **Resume agents with their work intact.** Resume existing Squad restores CLI and Modern agents with their assigned work preserved. Recovery checks that every agent can be restored before offering a resume.
- **Choose what happens when a run finishes.** Each Squad can keep its worktree, merge its changes into the base branch and remove it, or delete it. Keeping the worktree is the default; failed and stopped runs retain their work. A merge that cannot complete safely leaves the worktree available for review.
- **Give workers clearer assignments.** Work units include their verification steps and guidance for reporting progress during long commands, including when work is reassigned.
- **Respect routing during recovery.** A stalled kickoff moves only to an eligible worker; when routing leaves no suitable worker, Zana asks for help instead.
- **Retry planning consistently and clean up afterward.** Inferred plans remain available across retries, then their handoff files are removed when a run is dismissed, superseded or can no longer be retried.

## Threads and agents

- **Stop work cleanly.** Stopped thread messages settle as cancellations, so the interface can leave its busy state without treating the stop as a failed request.
- **Keep your Mac awake while threads work.** The existing keep-awake setting now covers active local Modern threads, including background workers, and releases the sleep blocker when work finishes or stops.
- **More reliable PI starts and forks.** New PI threads use supported permission defaults, and forks from completed replies retain the intended conversation history.
- **Fewer interruptions while composing.** Typing keeps focus during agent updates, slash-command suggestions stay visible, and the thread header follows the composer's current branch.
- **Smoother Cursor authentication.** Sessions complete the CLI sign-in handshake, and background availability checks avoid opening login pages.

## Scheduling

- **Find schedules that skipped their last run.** A new Scheduler filter and status pill show when a run was skipped and why, including a previous run that is still active.
- **Keep the active run visible.** An overlap skip gets its own history row instead of overwriting the running session. Long-running work stays visible in Recent runs even after repeated skips, and the schedule continues to point to its live session.
- **Use your Claude setup for scheduled work.** Choose your own Claude configuration globally or per schedule, or keep runs isolated. Isolated runs carry supported MCP launch settings; required MCPs are checked before launch so a missing tool produces an explicit failure.

## Plugins and desktop reliability

- **Restore bundled plugins locally.** Recovery uses the plugin files shipped with the app, without requiring a separate recovery download.
- **Keep plugin backends working after reinstalls.** Shared SDK app helpers are bundled into plugin backends, and missing-dependency messages explain when a plugin needs rebuilding or reinstalling.
- **Install Git plugins from their declared folder.** Marketplace installs preserve source subdirectories and version-tag prefixes. Temporary cleanup locks are retried without hiding the original install result or turning a successful update into a failure.
- **Fewer console windows on Windows.** Startup probes, Git operations and plugin source commands run without opening extra console windows.
- **Avoid repeated summary work.** Supported summary and classification requests can reuse recent identical results within bounded limits. Settings Usage shows reuse counters, and provider changes invalidate old results.

## Help and appearance

- **Get started with How To videos.** The website’s Getting Started page combines three setup steps with the same tutorial catalogue available in Zana. New Squads guides explain choosing, launching, monitoring and customizing a Squad.
- **Learn from the refreshed tour and Agentforce videos.** Help videos can update independently of desktop releases; the catalogue includes the Agentforce demonstrations.
- **More consistent light and dark themes.** Light-mode side panels have clearer backgrounds, and Resume after API errors fields follow the app theme.

Includes dependency security updates and cross-platform reliability fixes.
