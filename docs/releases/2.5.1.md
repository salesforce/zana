# What's new in 2.5.1

**Keep useful context close and everyday work flowing.** Annotate conversation passages, share compact context references with assistants, and spot skipped schedules more easily. This update also improves plugin recovery and thread reliability.

## Context and conversations

- **Annotate a passage in a thread.** Select text from a conversation and attach an annotation as context for your next message. Browser plugins can also contribute annotation actions to the browser toolbar.
- **Share selections without filling the composer.** Copy text from participating editors, documents and plugins, then paste an inspectable context badge into a thread or assistant composer. The captured text travels with your message, and compact references survive draft restoration and conversation history.
- **Ask an agent from Design Docs more reliably.** The assistant resolves the correct project machine, offers more room for agent selection, and accepts inspectable document passages as context.
- **Give previews more room.** Widen the document preview panel to read larger files, with safer handling of project file paths across platforms.

## Threads and agents

- **Stop work cleanly.** Stopped thread messages settle as cancellations, so the interface can leave its busy state without treating the stop as a failed request.
- **Keep your Mac awake while threads work.** The existing keep-awake setting now covers active local Modern threads, including background workers, and releases the sleep blocker when work finishes or stops.
- **More reliable PI starts and forks.** New PI threads use supported permission defaults, and forks from completed replies retain the intended conversation history.
- **Fewer interruptions while composing.** Typing keeps focus during agent updates, slash-command suggestions stay visible, and the thread header follows the composer's current branch.
- **Smoother Cursor authentication.** Sessions complete the CLI sign-in handshake, and background availability checks avoid opening login pages.

## Scheduling, recovery and Help

- **Find schedules that skipped their last run.** A new Scheduler filter and status pill show when a run was skipped and why, including a previous run that is still active.
- **Retry Squad planning consistently.** An inferred plan is retained across retries, with its absolute path available to the launched work.
- **Restore bundled plugins locally.** Recovery uses the plugin files shipped with the app, without requiring a separate recovery download.
- **Avoid repeated summary work.** Supported summary and classification requests can reuse recent identical results within bounded limits. Settings Usage shows reuse counters, and provider changes invalidate old results.
- **Learn from the refreshed tour and Agentforce videos.** Help videos can update independently of desktop releases; the catalogue includes the Agentforce demonstrations. Light-mode side panels also have clearer, consistent backgrounds.

Includes dependency security updates and cross-platform reliability fixes.
