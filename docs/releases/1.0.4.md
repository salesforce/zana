# What's new in 1.0.4

This is our biggest update yet — more ways to run agents, safer automation, and a much richer chat experience.

## ✨ New

- **Run agents with Codex, not just Claude.** Pick the coding assistant you prefer when you launch an agent.
- **Give each agent its own workspace.** Agents can now work in their own isolated copy of your project, so parallel agents never step on each other's changes. Each agent card shows the branch it's working on.
- **Next Steps.** Agents can now suggest concrete follow-up actions you can run with one click — each with a short reason why. Reports link to their related next steps.
- **Ask-me-anything prompts, in the app.** When an agent needs a decision, it can ask you a question right in the app instead of only in the terminal.
- **Approve-for-me mode.** Let trusted agents proceed on low-risk actions automatically, so you're not interrupted for every small approval. Off by default — turn it on in Settings.
- **Scheduled runs on a cron.** Schedule recurring agent tasks with precise timing, not just simple intervals.

## 💬 Improved

- **A richer Orchestrator Chat.** Live status while a command runs, cleaner formatting, an easy-to-scan diff view for file changes, and results from delegated agents now flow back into the conversation.
- **A calmer menu-bar popover.** A working-count badge, an attention dot when an agent needs you, and a quick inline reply — without opening the app.
- **Inbox that reads better.** Rows are titled by the task they came from, and broken links to documents are found and fixed automatically.
- **Remote sessions stay connected.** SSH connections are kept alive and reattach cleanly after a blip.
- **The `zcc` command works everywhere.** Every agent terminal can now run `zcc` out of the box.

## 🐛 Fixed

- Setting changes now apply immediately across all windows.
- Dense file diffs collapse correctly so you can actually read them.
- The app reliably keeps its place in the Dock.
- Agents no longer silently succeed when a reply couldn't be delivered — you'll be told.

---

_Some new capabilities (Codex agents, approve-for-me, isolated workspaces) start turned off — enable them in Settings when you're ready._
