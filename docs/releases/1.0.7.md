# What's new in 1.0.7

A harness-and-chat polish release: OpenCode joins the lineup as a first-class harness, the chat surface gets smarter about steering and context, agents live on a physical Stream Deck, and Settings keeps getting cleaner.

## ✨ New

- **OpenCode is a first-class harness.** Launch the `opencode` terminal agent from the New Agent modal like any other harness — the zcc-inbox tool is wired into every OpenCode tab automatically (no file written to your project), and the launcher knows OpenCode's own CLI shape so seed prompts and resume work correctly.
- **Agents on a Stream Deck.** Drive your agent kanban from a physical Elgato Stream Deck — spawn agents across providers, focus a session in-app, and fan out every ZCC capability from a single hub icon.
- **Install extensions straight from git.** Point at a git URL and install an extension end-to-end, with the same consent flow and starter-template kinds as the marketplace path.
- **A calmer, smarter chat surface.** A tri-state plan card lifts prose checklists into something you can track, per-turn thumbs up/down lets you rate orchestrator replies, and a rolling per-session digest gives new turns cold-start context. An ambient Aurora Grid background rounds out the redesign.

## 💬 Improved

- **Live status knows when an agent needs you.** OpenCode goes silent both at a permission prompt *and* when it asks you an interactive question — both now surface as "needs you" instead of quietly reading as "idle", so a waiting agent can't hide in the idle column.
- **Right-click everywhere.** List actions across the app are unified behind consistent right-click context menus.
- **The multi-model chat engine is always on.** No more opt-in toggle — pick a model from the composer or set a default backend in Settings.
- **Steer or queue, and recover cleanly.** Chat recovers gracefully from a rejected `claude --resume`, and delegation hints from prior runs surface when you ask a repeated question.
- **Cleaner Settings.** The Harness tab is reformatted into compact per-harness rows — glyph, name, live install badge, and an on/off switch, with the binary path (and PI's provider/model defaults) tucked behind an "Advanced" disclosure — matching the Editor and LLM Providers layout. New Terminal and Editor settings categories, and the "Interactive questions" toggle moved to the Agents tab.
- **A fresh empty state.** The orchestrator panel gets a fancy grid empty-state for when there's nothing running yet.

## 🐛 Fixed

- **OpenCode launches with a seed prompt.** Opening an OpenCode tab with an opening prompt no longer misfires as a bad `cd` into a directory named after your prompt — the seed prompt is delivered the way OpenCode's CLI expects.
- **Steadier remote dev boxes.** Raised the SSH connect timeout so cold, proxied remote dev boxes connect instead of timing out.
- **Honest agent detail.** Removed a misleading per-session cost line from the agent detail panel.
- **Composer layout.** Dictate and Improve-prompt stay on one row.

---

_The multi-model Chat engine is always available; pick a model from the composer or set a default backend in Settings. OpenCode, like the other non-Claude harnesses, authenticates via its own login — enable it and set its binary under Settings → Code Harness._
