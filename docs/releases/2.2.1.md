# What's new in 2.2.1

Zana 2.2.1 keeps documents readable while a thread is running, and tidies the session Info panel so git status is not shown twice.

## 🐛 Fixed

- **Document preview keeps its place.** Opening a Markdown file in the session side panel no longer jumps back to the top when the thread receives new content.
- **One git summary in Info.** When commit and PR controls are present, the Info tab no longer repeats branch, status, files, and pull request rows.
- **Agent modal chrome.** Unused task-shelf controls are removed from the CLI agent header.

---

_macOS downloads are provided for Apple Silicon (`*-arm64.dmg`) and Intel (`*-x64.dmg`)._
