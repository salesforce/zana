# What's new in 2.2.1

Zana 2.2.1 sharpens the live conversation workflow: approvals are easier to scan, the Changes panel becomes a full workbench, side-panel media previews are more reliable, agent input status is clearer, and the refreshed Zana brand assets are ready across the app and website.

## New

- **Refreshed Zana identity.** The app, tray, website, social previews, Stream Deck glyphs, and generated icon resources now use the updated Zana fairy artwork and favicon set.
- **Video previews in session panels.** Thread side panels can preview local video attachments through the product HTTP range reader, including CLI-agent workspace files.
- **Changes workbench.** The thread Changes panel now has a searchable file navigator, branch context, display options, and an in-panel commit flow for reviewed project diffs.
- **Input-request lifecycle tracking.** Codex `request_user_input` hooks now mark sessions as blocked while the agent is waiting and clear that status when input resolves or the turn is interrupted.
- **Demo and brand artifacts.** Product demo, simulated demo, compact approval, and brand-preview artifacts are captured for local review and sharing.

## Improved

- **Approval prompts are more compact.** Command approvals now show the command first, keep session grants visible, and tuck secondary metadata into a collapsible details block.
- **Thread side-panel polish.** File and video preview tabs preserve layout more consistently across narrow and secondary-panel views.
- **Diff review scales better.** Large changed-file lists can be browsed as a tree or list, selected files scroll into view, and compact toolbar controls keep the panel usable at narrow widths.
- **App-surface requests behave predictably.** JSON API helpers set content type for mutation requests even when the request body is omitted.
- **Agent status recovery is steadier.** Conversation host recovery and agent status tests cover blocked, unblocked, and pending-input transitions more directly.

## Fixed

- **CLI-agent video paths resolve correctly.** Video preview requests can fall back to the registered project path when a side panel is opened from a CLI-agent session id.
- **Codex hook notifications carry lifecycle context.** Permission, tool-use, and interrupt hooks now forward event bodies so unrelated output does not clear a real pending input request.
- **Reported UI regressions.** The thread lifecycle and compact approval E2E coverage now guards the reported layout regressions in approvals, secondary panels, and video previews.

_macOS downloads are provided for Apple Silicon (`*-arm64.dmg`) and Intel (`*-x64.dmg`). Video preview support depends on the file being inside an authorized project or thread-storage root._
