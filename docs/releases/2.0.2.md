# What's new in 2.0.2

A Command Center release focused on enrolling another machine from the app, a first-party Plugin Guide, richer plugin surfaces, and a clearer public website.

## ✨ New

- **SSH pairing from Settings → Machines.** Pick a host from your SSH config, run the enroll command in an in-app terminal, and join a remote machine without leaving Zana.
- **Plugin Guide.** A bundled Plugins hub map of every surface a plugin can own, with copy-for-agent text and links into installed plugin pages.
- **Plugins can add agent actions.** The SDK can register agent-card and Agents-board actions, and the Plugins hub lists what each install actually contributes.
- **Salesforce Agent Script playground.** The Salesforce plugin ships a Monaco playground for Agent Script work inside the plugin panel.
- **A one-time star nudge** in the app (and a matching banner on the public site) so people who like Zana can star the repo without hunting for it.

## 💬 Improved

- **Remote enroll and release builds** can use the public pairing relay (`ZCC_APP_URL` / `ZCC_RELAY_TOKEN` in the release workflow) so packaged apps pair the same way as a deployed site.
- **The public website** has a clearer visual system, docs, download, and marketplace entry points, with the live site linked from the README.
- **Agents board and chrome.** Plugin-driven card actions, tighter board/monitor layout, and the old status bar is gone so the shell has one less competing strip.

## 🐛 Fixed

- **The pairing relay token stays out of the renderer.** It is baked only into main/server, so the untrusted UI never sees the secret.

---

_Nothing to migrate. Existing projects, plugins, and enrolled machines keep working. Plugin Guide installs on first launch like other bundled plugins._
