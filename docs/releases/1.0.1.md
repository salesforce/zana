# What's new in 1.0.1

A smoother, faster release with polish across the terminal, agents, and inbox.

## ✨ New

- **Ask agents lettered multiple-choice questions.** When an agent needs a decision, it can offer you clear options to pick from — right in the inbox and on follow-ups. Pending questions are flagged so you don't miss them.
- **One launcher for starting agents.** The quick launcher and the full launch panel are now a single, consistent place to start an agent.
- **Slack recap on idle.** When an agent goes quiet, it can post a short summary into your Slack thread.
- **Stay awake while working.** Your Mac won't sleep out from under a running agent.

## 💬 Improved

- **A faster, smoother app.** Long lists and terminals render more efficiently, and a freeze when listing past Claude sessions is gone.
- **Cleaner diffs.** Unchanged regions collapse in the diff viewer so you see just the changes.
- **Scheduler.** A one-click "see what happened" report right on each run.
- **Tickets.** A shared sprint board with a per-person avatar filter.
- **Quieter automation.** Auto-closing an idle agent no longer leaves a breadcrumb in your inbox by default.

## 🐛 Fixed

- Scrolling up in the terminal no longer snaps back to the bottom during live output.
- Remote agent windows show the right title.
- The Agents badge counts only the project you're looking at.
- Inbox previews and report titles read cleanly instead of showing raw formatting.
