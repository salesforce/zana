# What's new in 2.1.1

A Command Center release that adds Mastra Code, a Settings browser surface, and an Inbox that opens on what needs you — plus pairing reliability and one Team composer.

## ✨ New

- **Mastra Code.** A first-party harness plugin shows up in the fleet and composer when the CLI is installed. Hide it from Settings like the other harnesses.
- **Settings → Browser.** Import cookies from Chrome, Edge, or Arc into a thread's automation partition, then drive an in-app desktop browser with find-in-page and Take over.
- **Inbox opens on attention.** Overview surfaces pending blocking questions and the AI summary. Reports and Unread are filter chips on the Feed, not a separate tab.
- **One Team composer.** Durable team runs share a single Team launch surface (structured or freeform) instead of a separate Job Team / Autonomous Team split.
- **Plugin catalog detail.** Browse opens an overview, permissions, and more from the same author. The hub hero walks through plugin archetypes you can create.
- **GitHub stars on zana-ide.com.** The public nav shows the live star count for `salesforce/zana`.

## 💬 Improved

- **Inbox read and keep state lives in main.** Markers persist across relaunch and extra windows instead of living only in the renderer.
- **SSH reconnect waits for a real handshake.** `/status` stays disconnected until the host is actually joined, so a racing enroll no longer looks online.
- **Remote join refuses Docker Desktop origins.** Adding another computer needs a public app URL or the SSH reverse-tunnel command — a Docker gateway address cannot enroll a peer.
- **Thread images open as a gallery.** Lightbox navigates every inline image and composer attachment in the turn.
- **Streaming markdown stays snappy.** Thread replies split into incremental pieces with cached syntax highlighting, so long answers don't freeze the timeline.
- **Close with follow-up shows progress.** The action cannot double-fire, the button says Closing…, and a sticky toast tracks the paper-trail until it finishes.

## 🐛 Fixed

- **Inbox read state survives relaunch.** Opening the app again no longer treats previously read items as unread.
- **Pairing enroll no longer races the websocket ack.** Standalone join waits for `host.hello-ok` before reporting connected.
- **Host daemon no longer dies on SSH stdin EPIPE.** A failed remote-host install (BatchMode reject, dropped ControlMaster) is an install error instead of taking down `pnpm dev`.
- **MCP listener recovers when its port is still bound.** After an electron-vite restart, a leftover MCP port falls back to an ephemeral port instead of leaving MCP down.
- **Composer Send works with absolute paths.** A prompt that starts with `/Users/...` is no longer treated as a slash command, so Enter launches instead of opening an empty typeahead.

---

_Nothing to migrate. Existing projects, plugins, and enrolled machines keep working. Pairing another computer still goes through this app's host daemon and the website relay._
