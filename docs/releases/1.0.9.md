# What's new in 1.0.9

A big one: a new Home dashboard for the whole workspace, per-agent model and CLI routing controls, richer extensions, a real Library with folders, and a long list of reliability fixes — plus a full rebrand to Zana.

## ✨ New

- **A Home dashboard for your whole workspace.** See open follow-ups, unread Inbox activity, and active agents across every project in one place, with a quick launcher for starting a new agent right from Home. It also includes short, actionable guides for creating extensions, scheduling work, personas, shortcuts, and the first-run tour.
- **Choose the model and CLI tool per persona.** Each agent role can now be pointed at a specific AI model and execution mode, with the app translating that choice correctly for whichever underlying tool it launches. Codex agents can browse and pick from the models actually available to them, and every launcher has a searchable model picker.
- **A real Library with folders.** Library documents live in an organized, cross-project folder tree instead of a flat list — create, move, and delete folders and documents from a new global Library view or per-project. You can also ask AI to enhance any selected text while editing a document, and quickly create a new document from the folder view.
- **Share squads between machines.** Export a squad (a team and every persona it uses) to a single file, and import it back later — handy for restoring a squad after an update or moving your setup to a new machine.
- **A focused notifications drawer.** The title-bar bell opens a lightweight view of unread questions and reports, so you can triage what matters without leaving your current work. Extensions can now push their own notifications into this system, and clicking one jumps you straight to the right place — the extension's own tab, not just the generic Inbox.
- **Extensions can bring their own tools with them.** An extension can now declare additional skills and connected tools for agents to use, and run setup/cleanup steps automatically when it's installed or removed — the app keeps everything in sync and cleans up state fully on uninstall. Extensions can also connect to a shared SSH machine list contributed by other extensions.
- **Build your own extensions faster.** The Extension Creator agent can now install and reload the extension it's building for you on demand, instead of waiting for a manual click, and a background watcher picks up your edits automatically while you're working in its folder.
- **Zana branding.** The app now goes by "Zana" throughout — logo, icon, and Dock artwork have been redesigned with a new fairy mark, with a clean, crisp menu-bar glyph.

## 💬 Improved

- **A calmer, more capable agent launcher.** The model/CLI picker no longer stretches oddly with only a couple of options installed, the "Advanced" section no longer breaks page scrolling, and Send/Continue buttons show their keyboard shortcut so you don't have to remember it.
- **Agent detail view got better.** The Report tab now has copy and download buttons, matching the rest of the app, and the terminal view can go full-screen for more room to work.
- **Fine-tune when terminals stay alive after a dropped connection.** You can now choose whether background persistence applies to local sessions, remote sessions, both, or neither, instead of one all-or-nothing switch.
- **A polished agents board.** Lanes and project groupings on the agent kanban board now have real panel backgrounds instead of flat hairlines, and profile icons dropped a distracting colored ring.
- **Clearer Settings.** Settings text can be selected and copied everywhere, a shared voice key is used consistently, and confusing wording around harness repair and legacy routing controls was cleaned up.
- **Quick Agent naming is smarter.** A scratch project created from a quick prompt renames itself to match its real git repository once one exists, instead of keeping an ugly auto-generated slug forever.

## 🐛 Fixed

- **Long-running terminals stay healthy.** The app now independently cleans up dead terminal sessions on a regular schedule (not only when a recurring job happens to run), preventing a slow leak that could eventually stop new agents from launching after long uptime or sleep/wake cycles.
- **Smoother startup.** The app recovers gracefully if its own startup bookkeeping fails partway through, and several under-the-hood hardening fixes reduce the chance of state getting corrupted or out of sync.
- **Copying a file path from the Inbox works reliably.** It no longer silently fails when the app window isn't focused.
- **"Yolo" (unrestricted) launch profiles work again** for Claude, Codex, and Cursor when no specific execution target is set.
- **OpenCode agents behave more consistently.** Sessions get proper auto-generated tab names, restarts resume the exact conversation you were in, remote OpenCode sessions are more stable, and the live status panel now shows real file/model/token details instead of staying empty.
- **Goal automation no longer gets stuck retrying forever** when an agent fails to launch — it now counts against the same retry budget as any other stalled attempt and gives up gracefully instead of hammering retries indefinitely.
- **Various extension polish.** Text inside extension panels can be selected again, and an extension is now validated up front at install time to catch problems earlier.

## 🧪 Experimental

- **Content Screen.** An optional experimental safeguard can inspect content coming back from web searches, fetches, and third-party tools for signs of an embedded attempt to hijack the agent. It warns the agent rather than blocking work, and stays off by default while it matures.

---

_The optional Content Screen is available in Settings → Experimental and is off by default. This release also completes Zana's move away from the in-app Chat experiment — the app's focus going forward is the terminal-based agent workflow you already use for launching, tracking, and reviewing agents across your projects._
