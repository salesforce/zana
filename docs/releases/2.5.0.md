# What's new in 2.5.0

**A more focused Studio and a more connected workspace.** Give each AgentScript its own window and assistant, reuse test scenarios and variables, and install related plugins together with clearer recovery controls.

## Agentforce Studio

- **Give each AgentScript its own workspace.** Open scripts in separate windows while keeping main-window tabs available. Each script keeps its own assistant conversation, side-panel tools, layout and window size. Moving a script between windows preserves unsaved edits.
- **Keep running work when switching scripts.** Preview conversations, simulations and role-play sessions reconnect when you switch agents, hide tools or reload. Pin a tool to one script while editing another.
- **Reuse scenarios and variables.** A shared Scenarios catalogue feeds Role-play and batch simulations. Reuse variable presets and define scenario-specific values when needed.
- **Inspect conversations and evidence.** Search test cases, open their details, and inspect traces and payloads on demand. Resizable panes, persistent controls and clearer test-view names make the workbench easier to navigate.
- **Improve failing conversations with the assistant.** Self-healing tests candidate changes against the same scenarios within a bounded attempt budget, checks for regressions, and presents the best tested change for review before saving.
- **Find Salesforce tools quickly.** A searchable launcher shares the header with AgentScript tabs. Flow controls are more compact, diagrams refit when panes resize, and query results show COUNT() totals correctly.

## Plugin packs

- **Review a collection before installing.** A pack lists its plugins and sources, identifies plugins already installed, and lets you choose optional members.
- **Keep your existing setup.** Pack installation preserves installed versions, sources, settings and disabled choices. Each plugin keeps its own configuration, sign-in and update controls.
- **Recover from partial installs.** Follow progress for each member and retry failed installations without reinstalling successful members.
- **Control membership changes.** New members require another review. Forgetting a pack removes the grouping while keeping its plugins and data.
- **Publish packs without changing old catalogues.** Marketplace maintainers can add an optional packs.json sidecar. Packs appear in Plugins without adding another sidebar destination.

## Plugins and recovery

- **More room for plugin details.** Browse plugin collections and open an individual plugin as a full page.
- **Recovery from Settings.** Development settings can restart the host daemon or recover plugin runtimes while preserving configuration and stored data.
- **Independent failures stay contained.** A failed provider or plugin has less impact on other launches, and interrupted plugin activation is checked before recovered runtimes start.
- **Recover degraded plugins together.** Reload them in one action, inspect partial failures and retry them. Automatic watchdog recovery stops after a bounded retry budget; manual reload gives a repaired plugin another chance. Plugin status updates appear live.
- **Reduce document-sync overhead.** Large paired-document transfers use less temporary memory, and peer approvals reach the current app instance.

## Projects, threads and Squads

- **Navigate across machines.** Project lists group by machine, remote catalogues sync automatically, and the machine and project picker separates the two choices.
- **Arrange conversations and tools.** Thread tabs and dockable tool panels make it easier to switch context. Tab menus include archive actions and clearer status icons.
- **Start chats with space to work.** A Project's New Chat opens as a full page, and the composer follows the current branch from live Project status.
- **More resilient Squad launches.** Modern ACP launch and planning fixes improve startup, and a stalled engineer can recover after an API error before asking for help.
- **Share precise editor context.** Copied code selections become compact, inspectable file-and-line chips in the assistant composer. Artifact cards and diagram previews take less space.
- **Keep useful handoffs.** Close with follow-up asks the agent to wrap up and captures a fuller session summary. CLI agents can be archived instead of deleted, and schedules can resume their latest run.
- **Manage busy workspaces.** Tool tabs offer bulk close actions, the browser resize handle stays visible, and the Inset workspace design gives everyone distinct navigation and content surfaces.
- **More reliable sessions.** Queued input, completed replies and resumed child turns retain their intended ownership. Automated sessions receive narrower tool and skill catalogues, and worktree setup completes before agents start.

## Help and everyday improvements

- **Find guidance in the app.** Help includes onboarding videos, a video catalogue and a version browser for release notes.
- **Clearer computer setup.** Remote-computer setup and switching are more direct, and the machine installer runs correctly.
- **Smoother navigation and desktop behavior.** Project Back responds promptly, windows open in the effective theme, and schedule rows display cron cadence correctly.
