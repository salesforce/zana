# What's new in 2.8.0

**Choose how Squads launch.** A Squad can now follow the session that launches it, use a global default, or pin CLI Agent or Modern, and you can override it per launch.

## Squads

- **Set a Squad launch mode.** The Squad editor's **Squad launch mode** field offers **Use default**, **Follow caller**, **CLI Agent** and **Modern**. **Use default** follows **Settings → Squads → Defaults → All Squads launch mode**. Squads that already pin CLI Agent or Modern keep that choice. A Squad with no saved choice now means **Use default**, which follows the caller and then your Default launch mode, instead of always running as CLI Agent. [#927](https://github.com/salesforce/zana/issues/927)
- **Pick a mode for one launch.** The New Agent Squad composer has a **Squad launch mode** picker with **Use Squad default**, **CLI Agent** and **Modern**. It is disabled when the Squad pins a mode.
- **Agents launching Squads follow the session they run in.** When an agent starts a Squad through MCP, **Follow caller** matches that agent's session type.
- **Know what happens on remote Projects.** Modern needs a local Project. An inherited Modern choice on a remote Project falls back to CLI Agent with a notice. An explicit Modern pick or pin is refused.
- **Runs keep their mode.** Zana decides the mode once per launch. Resume and recovery reuse it instead of deciding again.
