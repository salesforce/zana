# Product shots

The homepage product tour is live HTML fake-UI (`app/components/product-tour/`).
GitHub READMEs cannot run that React loop, so `docs/assets/product-demo.gif` is a
captured pass of one cycle for the repo README (click-through goes to the live
site). `agents-board.gif` remains on disk for other surfaces that still want a
motion still.

If you recapture a GIF, shoot at 2x with no customer data, access tokens,
personal paths, private repositories, or terminal history visible. Keep
important details inside the central 80% of the frame.
