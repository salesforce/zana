# Walkthrough constellation marks

Agent glyphs are reused from the corresponding in-repository plugin `icons/` directories. Their `currentColor` fill is resolved to pearl for the dark icon tiles (Agentforce uses blue). Claude retains its original brand color.

- Claude Code: `plugins/harness-claude`
- Codex: `plugins/provider-codex`
- Cursor: `plugins/harness-cursor`
- OpenCode: `plugins/harness-opencode`
- Grok Build: `plugins/harness-grok`
- Agentforce Code: `plugins/provider-afcode`
- Pi: `plugins/provider-pi`
- Mastra: `plugins/harness-mastracode`

Slack and GitHub PNG marks are copied unmodified from `plugins/slack-bridge-2ff2/icons/slack.png` and `plugins/github/icons/github.png`; source attribution is in those plugins’ icon READMEs.

The center tile uses the official full-color app icon, `public/zana-icon-512.png`, without recoloring or recreating its background.
