# Provider Usage

View Claude Code, Codex, and Cursor subscription windows across execution machines. Refreshes run on each execution host; provider credentials stay there. The plugin keeps the last reading when a host cannot be reached.

Optional bundled plugin. Install from Plugins to enable it.
