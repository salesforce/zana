An in-app map of every surface a ZCC plugin can own. Use it while you author a plugin, then copy a prompt and live-reload with `zcc plugin dev`.

## What you get

- A Plugin Guide panel that groups host surfaces: sidebar, thread, composer, settings, and more.
- Copy-for-agent actions that seed a Creator thread with the right surface names.
- The same roster the public Plugin Guide website uses.

## How it works

The guide reads the host's plugin surface list. It does not install plugins for you. After you change plugin code, `zcc plugin dev` reloads the running plugin.

## Requirements

Install this plugin from Browse. Keep the Creator or a shell open in the plugin project if you want live reload.
