# Thread list

Threads grouped by Project, with a pinned section, live status and unread markers,
search, and keyboard-accessible actions. Command-click or drag a thread into a split.
Rename, pin, mark read, stop, archive, and close with follow-up from the actions menu.

This bundled plugin provides the global and project sidebar thread lists. Project
navigation, CLI Agents and Job Teams remain owned by the host. Disable the plugin or select the host list in
Appearance to use the built-in fallback.
